## How It Works

### Interactive Simulation
The page uses JavaScript to simulate the actual Python sensor simulator:

```javascript
// Users can click buttons to run:
runNormalSimulation()  // Shows ✅ green sensors
runAttackSimulation()  // Shows 🚨 red alerts
runMixedSimulation()   // Shows realistic mixed traffic
```

### Terminal Output
Live scrolling terminal with color-coded messages:
- **Green**: Successful sensor data processing
- **Red**: Security alerts and anomalies
- **Yellow**: Warnings and status updates
- **Blue**: Informational messages
