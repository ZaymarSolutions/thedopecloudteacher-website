Cloud & AI Fundamentals Instructor Guide

This guide supports the six-module flagship course and is printable for class facilitation, substitutes, and cohort planning.

Course structure: 6 modules, guided labs, digital reflection, and a choice-based capstone.

Facilitation Principles

Teach

Lead with plain language, then connect the concept to a real cloud or AI example students can picture immediately.

Build

Every session should include one hands-on step that produces a visible artifact, screenshot, note, or finished task.

Check

Pause for quick understanding checks and use the workbook reflection prompts to confirm comprehension.

Advance

End each module by pointing students toward the next module and the final capstone path.

Course Flow

Module 1: Cloud and AI Foundations

  • Define AI and Cloud in human terms.
  • Show the Microsoft ecosystem and how tools compare.
  • Complete Microsoft and Azure account setup.

Module 2: Azure Portal Basics

  • Explain resource groups, subscriptions, regions, and storage.
  • Have students navigate the portal and open Microsoft Learn.
  • Verify each student can find the right resource blade on demand.

Module 3: First Build Lab

  • Walk through creating a VM, verifying networking, and storing files.
  • Model safe deletion and cleanup habits to control cost and clutter.
  • Capture one screenshot or evidence item before moving on.

Module 4: AI in Azure

  • Introduce Azure AI Services, prompt engineering, and Copilot.
  • Discuss AI ethics with concrete examples.
  • Guide the business assistant project as a structured mini-build.

Module 5: Security and Identity

  • Teach Entra ID, MFA, RBAC, Defender, and Zero Trust as a system.
  • Use secure-by-default language and reinforce why identity is the new perimeter.
  • End with a secure-environment lab and cleanup checklist.

Module 6: Capstone Delivery

  • Review the five student choice outcomes and help students pick one.
  • Set a project scope that can be finished and presented well.
  • Use the capstone page to evaluate completion and portfolio readiness.

Instructor Checklists

Before Class
  • Confirm Azure access and student accounts.
  • Open the workbook and capstone pages.
  • Review the lab machine or sandbox setup.
During Class
  • Keep demos short and student practice long.
  • Use direct observation to identify blockers early.
  • Ask for one verbal recap from a student before changing topics.
After Class
  • Capture attendance and progress notes.
  • Assign the next workbook section if needed.
  • Flag learners who need extra help before the next session.
