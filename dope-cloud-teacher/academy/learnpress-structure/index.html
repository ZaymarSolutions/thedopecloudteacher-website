LearnPress Course Structure

A single curriculum can serve self-paced learners, in-person cohorts, and certification prep when the content model stays consistent: course, section, lesson, quiz, and supporting resources.

Core Mapping

Use one source of truth for curriculum design across every delivery format.

Course

A complete program such as AZ-900 Prep, AZ-104 Prep, or the full Cloud and AI curriculum.

Section

A module or weekly topic grouping that moves learners through the curriculum in order.

Lesson

A single learning unit with explanation, visuals, guided practice, and optional downloadables.

Quiz

A knowledge check or practice exam used to reinforce learning and confirm readiness.

Delivery Paths

Online Self-Paced

Each certification track becomes its own course with sections for modules, lessons for concepts and labs, and quizzes for module checks. Certificates and progress tracking close the loop.

In-Person, 2 Hours

The course is a six-week blended program with lesson pages for prep, live notes, lab guides, and post-class review. Sections map to weeks and quizzes land at the end of each week.

In-Person, 45 Minutes

Short sessions use the same structure but with tighter lessons, shorter quizzes, and more flipped-classroom prep so class time stays focused and practical.

Recommended Lesson Flow

Part Purpose
Intro State the topic, outcome, and the real-world reason it matters.
Concept Explain the idea in plain language with one clean visual or comparison.
Practice Use a guided lab, prompt exercise, or walkthrough the learner can complete confidently.
Check End with a short quiz or reflection prompt to confirm understanding.
